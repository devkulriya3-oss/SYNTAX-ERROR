## Problem Statement: 
Event organizers often manage registrations and entry manually,
which can be slow, inefficient and prone to errors.
GatePass provides a digital event registration and check-in
system that allows organizers to register attendees, generate
unique QR-based passes and verify entry quickly at the event.

## Our Solution:
GatePass is a web-based event management and QR check-in
platform.
The system allows organizers to:
- Register attendees.
- Generate unique passes.
- Generate QR-based entry credentials.
- Verify passes using QR/manual code.
- Prevent duplicate check-ins.
- Monitor attendance in real time.
- Export attendance and audit reports.

## Features
1. Attendee Registration
Organizers can register guests by entering:
- Name
- Email
- Phone
- Company
- Ticket type
Each attendee receives a unique pass code.

2. QR-Based Pass
Every registered attendee receives a unique QR pass.
The QR/pass can be displayed and used at the event entrance.

3. QR / Pass Verification
Event staff can verify an attendee using:
- QR scanning.
- Manual pass-code entry.

4. Duplicate Check-In Prevention
Once a pass has been successfully used,
the system prevents the same pass from being used again.

5. Attendance Dashboard
The dashboard displays:
- Total registrations.
- Checked-in attendees.
- Not-arrived attendees.
- Attendance percentage.
- Ticket-wise attendance.

6. Attendance Reports
Organizers can view check-in logs and export:
- Attendee CSV.
- Check-in audit CSV.
